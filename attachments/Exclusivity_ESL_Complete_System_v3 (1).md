## 8. CHECKLIST DE QUALIDADE DO PRODUTO

### 8.1 Checklist de Cada Prompt

Antes de publicar, cada prompt deve passar por:

- [ ] Identity Lock está completo e no início do prompt
- [ ] Foto de referência é mencionada ("as in your attached reference image")
- [ ] Descrição de pele inclui textura realista (poros, imperfeições)
- [ ] Cabelo tem especificação de cor, textura e volume
- [ ] Maquiagem está alinhada com o estilo do módulo
- [ ] Roupa é descrita com detalhes (tecido, cor, corte)
- [ ] Ambiente tem iluminação específica (natural, studio, golden hour)
- [ ] Expressão facial combina com o objetivo da cena
- [ ] Ângulo da câmera está definido (close, medium, full body)
- [ ] Negative Prompt está incluído (quando a ferramenta aceita)

### 8.2 Checklist de Qualidade do Vídeo

- [ ] Rosto está idêntico à referência (Identity Lock mantido)
- [ ] Pele tem textura realista (nada de "plástico")
- [ ] Iluminação é fisicamente plausível
- [ ] Pose e expressão combinam com o objetivo
- [ ] Movimento evita distorção de rosto/mãos (nada rápido/complexo)
- [ ] Narração está sincronizada com gestos (workflow anti-lipsync)
- [ ] Disclosure de IA está presente (quando exigido por plataforma)
- [ ] CTA está claro no final do vídeo

### 8.3 Checklist de Qualidade do Produto Digital

- [ ] PDF está formatado para leitura mobile (60% dos compradores leem no celular)
- [ ] Prompts são copy-paste (zero edição necessária)
- [ ] Links para ferramentas estão atualizados
- [ ] Imagens de exemplo estão otimizadas (tamanho < 500KB cada)
- [ ] Índice está clicável (PDF interativo)

## 9. GUIA DE USO POR PLATAFORMA

### 9.1 Midjourney

**Funciona com:** Identity Lock + Prompt de Cena + Parâmetros

```
Formato:
[URL da imagem de referência] [Identity Lock completo], [Prompt de cena], 
--cref [URL] --cw 0 --ar 9:16 --style raw --s 50

Dicas:
- Use --cref com a URL da referência para travar o rosto
- --cw 0 mantém SÓ o rosto (não copia roupa/cabelo da referência)
- --style raw para menos "beleza plástica" da Midjourney
- --s 50 para seguir mais o prompt e menos a estética padrão
```

### 9.2 Flux (Black Forest Labs)

**Funciona com:** Identity Lock + Prompt de Cena + Image Guidance

```
Formato:
[Identity Lock completo], [Prompt de cena]

Configuração:
- Image Guidance: carregue a foto de referência
- Strength: 0.7-0.8 (equilíbrio entre prompt e referência)
- Aspect Ratio: 9:16 (vertical) ou 4:5 (Instagram)
- Steps: 30-50
- Guidance Scale: 3.5-4.5

Dicas:
- Flux segue prompts mais literalmente que Midjourney
- Seja específico na descrição de luz e ambiente
- Use "photorealistic human appearance" no final do prompt
```

### 9.3 Leonardo.ai

**Funciona com:** Identity Lock + Prompt de Cena + Image Guidance

```
Formato:
[Identity Lock completo], [Prompt de cena]

Configuração:
- Image Guidance: carregue a referência
- Guidance Strength: 0.6-0.75
- Model: Leonardo Kino XL ou Leonardo Phoenix
- PhotoReal: ON (para realismo máximo)
- Alchemy: OFF (menos "arte", mais foto)

Dicas:
- Leonardo Kino XL é o melhor para fotorealismo de pessoas
- PhotoReal + Image Guidance = consistência facial alta
- Use "Negative Prompt" do sistema para evitar rostos genéricos
```

### 9.4 Ideogram

**Funciona com:** Identity Lock + Prompt de Cena

```
Formato:
[Identity Lock completo], [Prompt de cena]

Configuração:
- Ratio: 9:16 ou 10:16
- Style: Photo
- Magic Prompt: OFF (para seguir seu prompt exatamente)

Dicas:
- Ideogram é excelente para texto na imagem (se precisar)
- Menos "artístico" que Midjourney, mais direto
- Boa opção gratuita com limite diário generoso
```

### 9.5 Kling AI (Image-to-Video)

**Funciona com:** Imagem gerada + Motion Prompt

```
Formato do Motion:
the exact same woman from the reference image, perfect facial consistency, 
identical face structure, [Motion específico do pack], 10 seconds

Configuração:
- Mode: Standard ou Professional
- Duration: 5s ou 10s
- Camera: Static (menos distorção) ou Slow Push In
- Negative Prompt: "fast movement, distorted face, extra fingers, 
  waxy skin, generic AI face"

Dicas:
- SEMPRE use a imagem gerada como referência (não gere vídeo do zero)
- Movimentos sutis funcionam melhor (micro-motion)
- Evite movimentos rápidos ou complexos (distorsão)
- Gere 3-4 variações e escolha a melhor
```

### 9.6 Luma Dream Machine

**Funciona com:** Imagem gerada + Text Prompt de movimento

```
Formato:
[Motion específico do pack], maintaining perfect facial consistency 
with the reference image, photorealistic, 10 seconds

Configuração:
- Duration: 5s
- Aspect Ratio: 9:16
- Camera: mantenha simples

Dicas:
- Luma é mais "criativo" que Kling — pode inventar movimentos
- Seja MUITO específico no motion prompt
- Use "maintaining perfect facial consistency" no início
```

### 9.7 Runway Gen-3

**Funciona com:** Imagem gerada + Motion Brush + Text Prompt

```
Formato:
[Motion específico do pack], photorealistic human movement, 
consistent identity, 10 seconds

Configuração:
- Use Motion Brush para controlar o que se move
- Camera Control: mantenha estático ou slow zoom
- General Motion: 3-5 (baixo = menos distorção)

Dicas:
- Runway é o mais avançado (e o mais caro)
- Motion Brush é essencial para controlar movimento
- Melhor resultado, mas exige mais ajuste
```
